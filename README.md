## 🧭 What I'm building toward

Most of my projects start from a system that has to keep working under conditions that aren't the happy path — a duplicate attendance scan, a port network with a node knocked out, a resume that doesn't fit any template. The interesting part isn't the model or the endpoint, it's what the system does when the input isn't clean.
